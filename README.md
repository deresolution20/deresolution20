## Featured Project

### [mlx-mcp-server](https://github.com/deresolution20/mlx-mcp-server)

> MCP server that routes Claude's eligible work — summarize, extract, refactor, review — to a local MLX model on Apple Silicon. Self-correcting structural and executable gates with automatic local → cloud fallback. Zero data leaves the machine for supported task types.
